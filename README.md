# AudioScript
This is a simple bash script I use to restart my Linux computer's audio stack.
## Installation
To add the script to your `$PATH`, move the file to `~/.local/bin`. You may need to make a `/bin` directory first. Next give the script execute permissions using `chmod +x restartAudioStack`. Then add `export PATH="$HOME/.local/bin:$PATH"` to the end of your .bashrc file located in your home directory. The script should now be executable from the terminal like any other command.
